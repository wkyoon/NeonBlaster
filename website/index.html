게임 특징

🎯

터치 조종

화면 어디든 드래그하면 가상 조이스틱이 생성되어 직관적인 조작이 가능합니다.

🔫

자동 발사

발사는 자동! 오직 회피와 조준에만 집중하세요. 콤보를 쌓아 점수를 폭발시키세요.

📝

단어 완성 시스템

타겟 글자가 표시된 적을 격추해 단어를 완성하세요. 완성 시 대박 보너스 점수!

🌊

웨이브 시스템

시간이 지날수록 적이 강해지고 빨라집니다. 과연 몇 웨이브까지 버틸 수 있을까요?

💥

화려한 이펙트

네온 파티클 폭발, 화면 흔들림, 플래시 효과로 스크린 가득 사이버펑크 감성!

🔊

절차적 사운드

외부 음원 파일 없이 실시간으로 합성되는 SFX. 가볍고 몰입감 있는 게임 경험.

게임 플레이

01

조작

화면 왼쪽을 드래그하여 함선을 이동시킵니다. 발사는 자동으로 이루어집니다.

02

타겟 글자

화면 상단에 현재 완성할 단어와 다음 타겟 글자가 표시됩니다. 녹색으로 빛나는 적이 타겟!

03

격추 & 콤보

적을 연속으로 격추하면 콤보가 쌓이며 점수 배율이 최대 5배까지 증가합니다.

04

단어 완성

단어의 모든 글자를 채우면 대박 보너스 점수와 축하 이펙트가 펼쳐집니다!
